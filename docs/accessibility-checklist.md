# Accessibility Checklist

- [ ] Every interactive control is reachable by keyboard.
- [ ] Focus indicators remain visible.
- [ ] Inputs have programmatic labels.
- [ ] Errors are described in text, not color alone.
- [ ] Heading levels follow a logical hierarchy.
- [ ] Text and controls have sufficient contrast.
- [ ] Icon-only controls expose accessible names.
- [ ] Dynamic updates are announced where appropriate.
- [ ] Zoom and responsive layouts do not hide essential actions.

Test with keyboard-only navigation and at least one screen reader before release.
