# Definition of Done

A change is ready to merge when applicable criteria are met:

- [ ] Acceptance criteria are satisfied.
- [ ] Code follows established project conventions.
- [ ] Inputs, errors, and loading states are handled.
- [ ] Access control is enforced at the correct trust boundary.
- [ ] Automated tests are added or updated.
- [ ] Relevant tests have been run and actual results recorded.
- [ ] User-facing behavior and configuration are documented.
- [ ] No secrets, private data, or unrelated artifacts are included.
- [ ] Responsive and accessibility checks are completed for UI changes.
- [ ] Known limitations and follow-up work are documented.
