# UI Review Checklist

## Layout
- [ ] Spacing and alignment are consistent.
- [ ] Primary actions are visually clear.
- [ ] Tables and cards handle long content.
- [ ] Empty, loading, and error states are designed.
- [ ] Responsive behavior is checked at mobile, tablet, and desktop widths.

## Interaction
- [ ] Buttons show appropriate disabled/loading states.
- [ ] Forms explain validation errors near the relevant field.
- [ ] Destructive actions require suitable confirmation.
- [ ] Navigation and active states are consistent.

## Quality
- [ ] No placeholder copy remains.
- [ ] No broken icons or images remain.
- [ ] Contrast and keyboard focus are visible.
